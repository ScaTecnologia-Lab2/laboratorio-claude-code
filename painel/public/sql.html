Console SQL

Converse direto com o banco de dados PostgreSQL do container: veja as tabelas, faça consultas e teste alterações com segurança.

O que você está vendo nesta tela

O LabSystem guarda usuários, clientes, produtos e outros dados em um banco PostgreSQL (um container no Docker, um pod no Kubernetes). SQL é a linguagem para perguntar e alterar esses dados. Aqui você escreve o SQL, clica em Executar e vê o resultado.

Tabelas (à esquerda)
Cada tabela é como uma planilha: colunas (campos) e linhas (registros). Clique no nome para ver as colunas e o tipo de cada uma; chave marca a chave primária (o identificador único da linha). Clicar em Consultar escreve um SELECT pronto.
Os 3 modos de execução
Somente leitura (padrão): só consulta. O próprio PostgreSQL recusa qualquer INSERT, UPDATE, DELETE, CREATE… Pode experimentar à vontade.
Simular escrita: executa a alteração, mostra quantas linhas seriam afetadas e desfaz tudo no final (ROLLBACK). Ótimo para testar um UPDATE ou DELETE sem risco.
Gravar de verdade: a alteração é permanente. Exige marcar uma confirmação.
Uma instrução por vez
O painel roda um comando de cada vez (é isso que impede furar o modo somente leitura). Não coloque vários comandos separados por ;.
Proteções
Consultas que passam de 10 segundos são canceladas, a tela mostra no máximo 500 linhas, a coluna senha aparece sempre oculta e comandos que mexem em arquivos do servidor (COPY etc.) são bloqueados.

Cuidado: este console usa o banco do Docker Compose (…). O banco do Kubernetes é outro, separado. E lembre: npm run test:integration apaga a tabela de usuários, então nunca o rode contra este banco.
