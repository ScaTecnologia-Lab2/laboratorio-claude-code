Kubernetes

O Kubernetes roda os mesmos containers, mas em vários "computadores" ao mesmo tempo, repõe o que cair e cria mais cópias quando há muita demanda.

O que você está vendo nesta tela

Os dados vêm de kubectl get e kubectl top, atualizados a cada 5 segundos. Leia de cima para baixo: do cluster até cada pod.

Cluster e Nó (Node)
O cluster é o conjunto de computadores. Cada computador é um nó. Neste laboratório são 3 (1 que comanda, o control-plane, e 2 worker que fazem o trabalho), todos simulados como containers pelo k3d.
Pod
A menor unidade do Kubernetes: um (ou mais) container(s) rodando juntos. Cada quadradinho do Mapa do cluster é um pod. Se um pod morrer, o Kubernetes cria outro no lugar.
Pronto (Ready) 1/1
Quantos containers do pod passaram no teste de prontidão (readiness probe). Um pod só recebe tráfego quando está pronto.
Reinícios
Quantas vezes o Kubernetes religou o container do pod. Número que sobe sempre indica um programa que falha.
Deployment
A "ordem" que diz quantas cópias (réplicas) de um pod devem existir e qual imagem usar. Ao trocar a imagem, ele faz a atualização aos poucos (RollingUpdate), sem derrubar o sistema.
StatefulSet
Parecido com o Deployment, mas para quem guarda dados (o banco): o pod tem nome fixo (postgres-0) e um disco próprio.
Service
Um endereço estável para um grupo de pods (os pods mudam de IP o tempo todo). ClusterIP só é acessível dentro do cluster; LoadBalancer abre uma porta para fora e distribui as visitas entre os pods.
HPA (autoescala)
Observa o uso de CPU e liga mais pods quando passa da meta (e desliga quando a carga baixa), sempre entre o mínimo e o máximo. Para vê-lo agir: sh scripts/k8s/teste-carga.sh dev 60 4.
Namespace
Uma "pasta" que separa ambientes dentro do mesmo cluster: labsystem-dev (testes, porta 8081) e labsystem (produção, porta 8080, entregue pelo Argo CD).

Mapa do cluster — nós e pods

Cada caixa é um nó (um computador do cluster). Dentro dela, cada quadrado é um pod. Verde pronto, amarelo ligando/saindo, vermelho com falha. Clique num pod para ver os logs.
